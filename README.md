# Zomato-Data-Analysis-using-EDA

This project involves comprehensive analysis of Zomato's restaurant dataset to uncover insights regarding customer preferences, restaurant types, and spending behavior. The analysis is conducted using tools such as Jupyter Notebook, Excel, Power BI, and Tableau, making it accessible to a wide range of users.

🔍 Data Insights This project utilizes Python libraries such as Pandas, Matplotlib, and Seaborn to analyze restaurant data, providing insights into various factors like ratings and order preferences.

📈 Business Improvement Goals By visualizing customer data and generating insights, the goal is to provide actionable recommendations for Zomato to enhance its service offerings and strategic decisions. Documentation and demo videos are included to ensure clarity and usability
